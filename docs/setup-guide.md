# 設置と初期設定（主催者向け）

## 1. 用意するもの
- メールアドレス
- Cloudflare の無料アカウント（https://dash.cloudflare.com/sign-up 。クレジットカード不要）
- GitHub の無料アカウント（https://github.com/signup ）
  - 「Deploy to Cloudflare」ボタンは、このプログラムのコピーをあなたの GitHub に作り、そこから Cloudflare に設置します。

## 2. 合言葉を決める
最初の管理者を作る時に1回だけ使う合言葉です。**12文字以上**の推測されにくい文字列にして、メモしてください（短すぎるものや見本のままのものは、初期設定の時に断られます）。

## 3. 設置する
1. README の「Deploy to Cloudflare」ボタンを押す。
2. Cloudflare にログインし、GitHub とつなぐ（許可の画面では、作られるリポジトリへのアクセスを許可してください）。
3. 設定画面：
   - **Worker の名前**：そのままで大丈夫です（`narabooth`）。同じアカウントに2つ目を作る時は別の名前にしてください。
   - **SETUP_TOKEN**：2 の合言葉を入れる。
4. 「Create and deploy」を押し、数分待つ。完了するとアドレス（`https://narabooth.〜.workers.dev`）が表示されます。
   - アドレスが開けない時は、Cloudflare の Worker の画面の「Domains」（または Settings の Domains & Routes）で、`workers.dev` のスイッチがオンになっているか確認してください。

## 4. 初期設定
1. `https://〈あなたのアドレス〉/setup.html` を開く。
2. 合言葉、イベント名、最初の管理者の役割名（例：責任者）とパスワードを入れて作成する。
3. `https://〈あなたのアドレス〉/staff/` からログインし、「管理」タブの「📖 使い方（説明書）」に沿って準備する。
   - 管理者は2人以上登録しておくのがおすすめです（全員がパスワードを忘れると、初期設定画面では作り直せません）。

## 5. 更新について
- 設置後のプログラムは、あなたの GitHub に作られたリポジトリにあります。そのリポジトリの `main` を更新すると、Cloudflare が自動で反映します。
- 更新の瞬間は全端末の接続が一度切れます。**営業中の更新は避けてください。**

## 6. 注意
- 合言葉やパスワードを GitHub（リポジトリ）に書かないでください。
- 無料の範囲を超えても課金はされませんが、その日は動かなくなります。同じ Cloudflare アカウントで他のサイトを動かしている場合、無料枠はそれらと共有です。
