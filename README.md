# ならブース

イベントの**ブース受付・順番待ち**を、スタッフのスマホと参加者のスマホで管理するシステムです。
文化祭・学園祭、謎解き、体験コーナー、展示、ワークショップなど、ブースごとに順番に案内する催しで使えます。

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/narabooth/narabooth)

## できること
- **受付**：番号（例：A12）と4桁の確認コードを発行。人数・料金（0円＝無料も可）を記録
- **参加者**：会場に掲示した QR を読み取り、番号とコードを入れると、順番・待ち時間の目安・呼び出しをスマホで確認（アプリ・登録不要）
- **ブース**：呼び出し・開始・終了・不在・一時停止。スタッフの端末同士は自動で同期
- **お知らせ・連絡**：参加者へのお知らせ、スタッフ間のチャット、対応依頼
- **集計**：組数・人数・金額をブース別・営業日別に表とグラフで表示し、Excel に保存
- ブースは最大10個、営業日は何日でも。参加者の画面の文章、協賛・お知らせ枠も設定可能
- スタッフ用 Android アプリ「ならブース」（準備中）でも使えます

## なぜ Cloudflare を使うの？
Cloudflare（クラウドフレア）は、インターネット上に**あなたのイベント専用の置き場（サーバー）**を無料で作れるサービスです。この置き場があるから、次のことができます。

- 📱 **参加者は会場の QR コードを読み取るだけ**で、自分のスマホで順番・待ち時間の目安・呼び出しを見られます（参加者はアプリも登録も不要）
- 🔄 **スタッフのスマホ同士がすぐ同期**します。受付で番号を出すと、ブースの係のスマホにもすぐ表示されます
- 💬 **スタッフ同士のチャット**や「対応依頼」、参加者への**お知らせ**が送れます
- 📊 人数・金額の**集計と Excel 保存**ができます
- 🔒 予約などのデータは**あなたのアカウントの中だけ**に保存され、ならブースの作者も見られません

## 費用
- 主催者ごとに、**自分の Cloudflare の無料アカウント**に設置して使います（データは自分のアカウントの中だけに保存されます）。
- 無料プランの範囲で動くように作っています。無料の範囲を超えても**自動で課金されることはなく**、その日は動かなくなるだけです（日本時間 9:00 に回復）。
- 目安：1日に約500組（3ブース×160組）を受け付けても、無料枠の1〜2割程度の使用量でした（手元での負荷試験）。

## 設置のしかた（10〜15分）
用意するもの：メールアドレス、Cloudflare の無料アカウント、GitHub の無料アカウント（どちらも途中で作れます。クレジットカードは不要）

1. **合言葉を決める**：最初の管理者を作る時に1回だけ使う合言葉（12文字以上の推測されにくい文字列）を決めて、メモします。ならブースのアプリの「主催者の方へ」で作ることもできます。
2. 上の **「Deploy to Cloudflare」ボタン**を押します。
3. Cloudflare にログインし、GitHub とつなぎます（アカウントが無ければ無料で作れます）。
4. 設定画面の **SETUP_TOKEN** に、1 の合言葉を入れます。ほかの欄はそのままで大丈夫です。
5. 「Create and deploy」を押して、数分待ちます。完了すると `https://narabooth.〜.workers.dev` のようなアドレスが表示されます。
6. そのアドレスの最後に `/setup.html` を付けて開き（ならブースのアプリでは「主催者の方へ」の手順3）、合言葉・イベント名・管理者の役割名とパスワードを入れて初期設定をします。
7. `https://〜.workers.dev/staff/` から管理者でログインし、「管理」タブの **📖 使い方（説明書）** に沿って準備します。

詳しくは [docs/setup-guide.md](docs/setup-guide.md) を見てください。

## ページ
| アドレス | 内容 |
|---|---|
| `/` | 参加者用ページ（掲示する QR の行き先） |
| `/staff/` | スタッフ用ページ（ログイン）。「管理」タブに使い方（説明書） |
| `/setup.html` | 初期設定（最初の1回だけ） |
| `/qr.html` | 掲示用 QR コードの作成・印刷（管理タブから開きます） |

## 開発者向け
```bash
npm install
cp .dev.vars.example .dev.vars   # SETUP_TOKEN を自分で決めて書く（12文字以上）
npm run dev          # http://localhost:8787
npm test             # 自動テスト（Chromium が必要）
```
Cloudflare Workers（Static Assets）＋ Durable Objects（SQLite）で動作します。
